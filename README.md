# Stockroom

Stockroom is a Myntra-inspired product discovery catalog built with Angular and Spring Boot. Users can register, sign in, browse categories, and use the built-in smart finder to find close product matches, including common spelling mistakes. Admins manage the product catalog.

## Live application

- **Storefront:** [https://product-frontend1.onrender.com](https://product-frontend1.onrender.com)
- **Products API:** [https://product-api-xv02.onrender.com/api/products](https://product-api-xv02.onrender.com/api/products)

The backend currently uses an in-memory H2 database. Products and user accounts are temporary and are lost whenever the Render service restarts or sleeps. Configure a persistent database before using this for real customer accounts or long-term catalog data.

## Features

- Responsive, fashion-inspired product discovery storefront
- Search recommendations ranked by product name, category, and description, with typo-tolerant matching
- Category filtering and optional product images
- User registration, sign-in, and logout
- Admin-only product creation, editing, and deletion, enforced by the API
- Password hashing with BCrypt and signed, expiring JWT access tokens
- Admin account bootstrapped from private Render environment variables
- Angular 19 server-side rendering and Spring Boot REST API

The product finder uses local matching logic; it does not call an external AI service or require an AI API key.
On first startup with an empty database, the backend adds eight sample products across several categories so the storefront is ready to explore. Admins can edit or remove these sample listings.

## Technology

- Angular 19, TypeScript, RxJS
- Spring Boot 3, Spring Data JPA, Spring Security
- H2 in-memory database for the current demo deployment
- Stateless JWT authentication

## Local development

### Frontend

```bash
npm ci
npm start
```

Open [http://localhost:4200](http://localhost:4200).

### Backend

```bash
cd springbootwithangular
mvn spring-boot:run
```

The API is available at [http://localhost:8080/api/products](http://localhost:8080/api/products). Configure `ADMIN_EMAIL`, `ADMIN_PASSWORD` (at least 12 characters), and `AUTH_JWT_SECRET` (at least 32 UTF-8 bytes) to enable admin login and persistent token signing.

## Deploy on Render

The repository includes a Render Blueprint in [`render.yaml`](./render.yaml) for both services. Create or sync the Blueprint from the repository root. Set these **private backend environment variables** in Render:

- `ADMIN_EMAIL`: email for the initial administrator
- `ADMIN_PASSWORD`: administrator password of at least 12 characters
- `AUTH_JWT_SECRET`: automatically generated by the Blueprint; if setting manually, use at least 32 characters

Never commit credentials or secrets to GitHub. Registration creates a standard user account; only the configured admin can manage products. The frontend receives the backend URL from the API service automatically.

For persistent production data, replace the H2 dependency with a supported external database and configure its connection details as Render environment variables.
